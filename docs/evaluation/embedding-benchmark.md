## What this does and does not settle

**Both sides of every pair here are prompts.** Production embeds a student's
essay - hundreds of words of narrative prose - against a prompt of a few dozen.
A larger model's advantage, if it has one, is most likely to appear on exactly
the long-text side this benchmark never exercises, so a model losing here is
not shown to be worse in the app. It is shown not to be better on the one
comparison that can be made offline and deterministically today.

Re-run this against real essays before treating a negative result as final.
That check needs essays, which is the same thing every other part of this
evaluation is waiting on.

The instruction prefix is load-bearing and is the reason the first run of this
benchmark was wrong. BGE without its retrieval instruction fails three
calibration positives; with it, it passes all twenty. Any future candidate has
to be run in the form its model card specifies, or the benchmark measures the
prefix.
